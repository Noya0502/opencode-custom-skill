JavaScript 六种基础数据类型

STRING · NUMBER · BOOLEAN · UNDEFINED · NULL · SYMBOL

S
String 字符串
由零个或多个字符组成的文本，使用单引号或双引号包裹
N
Number 数值
整数与浮点数，包含 NaN、Infinity 等特殊值
B
Boolean 布尔
只有 true 和 false 两个字面量，用于逻辑判断
U
Undefined 未定义
变量声明后未赋值时的默认值
∅
Null 空
表示"空值"，通常用于主动清空对象引用
Sym
Symbol 符号
ES6 新增，每个 Symbol 值都独一无二，常用作对象属性名
▸ 运行结果（typeof 演示）
注：Symbol 是 ES6 新增的第六种基础（原始）数据类型；ES2020 又新增了 BigInt。 另外，typeof null 返回 "object" 是 JavaScript 早期的历史遗留 Bug，判断 null 应使用 hgj_nullValue === null。
