⚠️ setInterval 漂移问题 & 正确姿势

你可能已经发现：setInterval 并不是精准的「每隔 N 毫秒」。主线程卡顿、浏览器后台节流都会让它越跑越飘。
✅ 正确做法：用 setTimeout 递归 + 记录首次时间戳，按「真实经过时间」计算下一次延时，抵消漂移。

// 漂移修复方案：基准时间戳 + setTimeout 递归 let hgj_base = Date.now(); function hgj_fixedInterval() { const drift = Date.now() - hgj_base; console.log('实际漂移：' + drift + 'ms'); // 下一次触发 = 理想时间 - 当前漂移 const nextDelay = 1000 - drift % 1000; hgj_timerId = setTimeout(hgj_fixedInterval, nextDelay); }
